Each country is a <g id="xx" class="landxx coastxx xx"> element, where "xx"
is the country's ISO 3166-1 alpha-2 code in lowercase (e.g. id="us", "gb",
"il", "ps"). Verified against src/common/geo_taxonomy.py's COUNTRY_LIST
(94 codes) with zero codes missing from this map.

Used inline (embedded directly in generated homepage HTML, not referenced
via <img>) so JavaScript can select and color individual <g id="xx">
elements and attach click handlers - an <img>-referenced external SVG
does not allow DOM access to its internals.
