# geopolitics-tracker

מערכת לסקירה יומית של מאמרי פרשנות גאופוליטית מתוך PDF-ים של עיתונים מובילים באנגלית וגרמנית. המערכת מנתחת דגש ומגמות לאורך זמן ומפיקה דוחות יומיים, שבועיים וחודשיים (PDF + HTML אינטראקטיבי), המתפרסמים באתר ב-GitHub Pages.

כל הדוחות והאתר זמינים בשתי גרסאות שפה מלאות - עברית ואנגלית, עם אפשרות מעבר שפה באתר.

לפרטים על ארכיטקטורת ה-Pipeline ומוסכמות העבודה בפרויקט, ראו [CLAUDE.md](CLAUDE.md).
