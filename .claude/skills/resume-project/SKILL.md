# Resume Project

בצע שחזור מסודר של מצב הפרויקט והמשך מהנקודה שבה הסתיים הסשן הקודם.

1. אם הפרויקט מנוהל ב-git: בדוק תחילה `git status`. אם יש שינויים מקומיים שטרם בוצע להם commit ועלולים להתנגש - עצור ודווח למשתמש במקום להמשיך, אל תסתיר או תדרוס אותם. אחרת, הרץ `git pull` כדי להביא את המצב העדכני ביותר מה-remote (חשוב כשעוברים בין כמה מחשבים), **לפני** קריאת CLAUDE.md/HANDOFF.md. אם ה-pull נכשל (למשל קונפליקט) - עצור ודווח, אל תנסה לפתור קונפליקטים באופן אוטומטי.

2. קרא מחדש מהדיסק את הקובץ CLAUDE.md במלואו.

3. קרא את הקובץ HANDOFF.md במלואו.

4. אם קיים קובץ PROJECT_LOG.md בשורש הפרויקט - קרא אותו במלואו גם כן. אם הוא לא קיים - דלג בלי הערה.

5. בדוק את מבנה הקבצים והתיקיות הנוכחי של הפרויקט.

6. בדוק את הקבצים הרלוונטיים למשימה הפתוחה המתוארת ב-HANDOFF.md, כדי לוודא שמצבם בפועל תואם ליומן המסירה.

7. אם הפרויקט מנוהל באמצעות Git:
   - בדוק git status
   - בדוק אם קיימים שינויים שטרם בוצע להם commit
   - אל תשנה את מצב המאגר בשלב הבדיקה

8. השווה בין:
   - ההוראות הקבועות ב-CLAUDE.md
   - מצב הפרויקט המתואר ב-HANDOFF.md
   - מצב הקבצים בפועל

9. הצג תחילה סיכום קצר הכולל:
   - מטרת הפרויקט
   - מה כבר הושלם
   - מהי המשימה הפתוחה
   - אילו קבצים רלוונטיים להמשך
   - בעיות או סתירות שהתגלו
   - הצעד הבא שאתה עומד לבצע

10. אם הצעד הבא ברור ואינו סותר את CLAUDE.md, המשך לבצע אותו מהנקודה שבה הופסקה העבודה.

11. אם קיימת אי-בהירות, סתירה או שחסר מידע חיוני, אל תנחש. עצור ושאל שאלה ממוקדת אחת לפני ביצוע שינויים.

12. אל תחזור על עבודה שכבר הושלמה.

13. אל תשנה את CLAUDE.md או את HANDOFF.md במסגרת פתיחת הסשן, אלא אם אבקש זאת במפורש.
