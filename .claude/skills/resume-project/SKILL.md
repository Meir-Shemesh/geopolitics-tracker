# Resume Project

בצע שחזור מסודר של מצב הפרויקט והמשך מהנקודה שבה הסתיים הסשן הקודם.

1. קרא מחדש מהדיסק את הקובץ CLAUDE.md במלואו.

2. קרא את הקובץ HANDOFF.md במלואו.

3. בדוק את מבנה הקבצים והתיקיות הנוכחי של הפרויקט.

4. בדוק את הקבצים הרלוונטיים למשימה הפתוחה המתוארת ב-HANDOFF.md, כדי לוודא שמצבם בפועל תואם ליומן המסירה.

5. אם הפרויקט מנוהל באמצעות Git:
   - בדוק git status
   - בדוק אם קיימים שינויים שטרם בוצע להם commit
   - אל תשנה את מצב המאגר בשלב הבדיקה

6. השווה בין:
   - ההוראות הקבועות ב-CLAUDE.md
   - מצב הפרויקט המתואר ב-HANDOFF.md
   - מצב הקבצים בפועל

7. הצג תחילה סיכום קצר הכולל:
   - מטרת הפרויקט
   - מה כבר הושלם
   - מהי המשימה הפתוחה
   - אילו קבצים רלוונטיים להמשך
   - בעיות או סתירות שהתגלו
   - הצעד הבא שאתה עומד לבצע

8. אם הצעד הבא ברור ואינו סותר את CLAUDE.md, המשך לבצע אותו מהנקודה שבה הופסקה העבודה.

9. אם קיימת אי-בהירות, סתירה או שחסר מידע חיוני, אל תנחש. עצור ושאל שאלה ממוקדת אחת לפני ביצוע שינויים.

10. אל תחזור על עבודה שכבר הושלמה.

11. אל תשנה את CLAUDE.md או את HANDOFF.md במסגרת פתיחת הסשן, אלא אם אבקש זאת במפורש.
